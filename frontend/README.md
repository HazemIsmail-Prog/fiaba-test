# FIABA frontend app

Vue 3 app for logged-in staff and clients.

```bash
npm install
npm run dev
```

Runs at `http://localhost:5174`. The API must be running on port 3000.

Demo password: `fiaba123`

- `admin@fiaba.local` — full access, including website CMS
- `client@fiaba.local` — events, contracts, meetings, appointments
